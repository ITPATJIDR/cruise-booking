## Galleries for discovery

- siteinspire.com — curated, filterable by style and type
- minimal.gallery — restrained, typography-led sites
- fontsinuse.com — real-world font pairings by category
- typewolf.com — font pairings and site-of-the-day with fonts named
- brutalistwebsites.com — rule-breaking layouts (use for courage, not as a style)
- awwwards.com — useful, but many winners prioritise effects over usability; check the actual reading experience

## Thai references

Look for Thai brands, publishers and studios that use Thai typography well (looped vs loopless choices, line-height, Latin pairing). Note in each case file how Thai and Latin are paired.
