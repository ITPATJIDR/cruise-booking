# Case file: Pentagram

- **URL:** https://www.pentagram.com/
- **Direction:** Swiss / Gallery
- **Physical object it evokes:** a design annual / museum wall labels
- **Analysed:** 2026-10-28

## Tokens

| Token | Value | Note |
|---|---|---|
| Fonts | Plain (single neo-grotesk), almost all weight 400 | Hierarchy from size and grey, not weight |
| Body | 19px / 25px, `#1a1a1a` | Generous body size |
| Type sizes in use | 13 · 16 · 19 · 32 · 52 | Five sizes, clean steps |
| Greys | `#767676`, `#8c8c8c`, `rgba(0,0,0,.56)`, `rgba(255,255,255,.56)` | Fixed alpha levels for secondary text on any background |
| Surfaces | white, `rgba(0,0,0,.07)` chips, `#222` inverted sections | |
| Radius | 4px (dominant), pill for a few controls | |
| Grid | `12px 718px` caption+content pairs; 4 equal columns for work | Asymmetric label column |

## Signature moves

1. **Interactive sentence**: "We design [Brand Identity ▾] for [Technology ▾]" — the filter is written as a sentence.
2. **Work-first hero**: a large project image with a small caption (client + one-line description) in the corner.
3. **Single typeface discipline**: one family at regular weight throughout; inverted dark sections for stories ("The Secret Life of Things").

## Why it works

A design firm proves taste through restraint and the work itself. The sentence filter turns navigation into a statement of what they do. One typeface and fixed grey levels keep everything quiet so the projects are loud.

## How to adapt

- Turn filters or navigation into a readable sentence with inline selectors.
- Use fixed alpha greys (.56, .07) so secondary text works on light, dark and image backgrounds.
- Try a single family at one weight; force hierarchy through size, colour and placement.

## Watch-outs

- Restraint without strong imagery reads as empty. Only choose this when the work is great.
