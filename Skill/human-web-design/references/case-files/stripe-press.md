# Case file: Stripe Press

- **URL:** https://press.stripe.com/
- **Direction:** Editorial / Publisher
- **Physical object it evokes:** a shelf of cloth-bound books
- **Analysed:** 2026-10-28

## Tokens

| Token | Value | Note |
|---|---|---|
| Fonts | Ivar Headline + Ivar Text (serif) with Georgia fallback | Serif-only system |
| Body | 16px, white on `#201819` | Warm brown-black, like a dark bookshop |
| Headings | H1 17.6px, H2/H3 16px, weights 400–600, tracking +0.02em | Headings are *the same size as body* |
| Type sizes in use | 14 · 16 · 17–18 · 21 · 25 | Very few, very close |
| Colour | Comes from each book cover (gold, teal, crimson, slate, cream) | The page has no brand accent of its own |
| Radius | 2–3px | Print-like corners |
| Container | book column ~470px wide in a very wide canvas | The column is the shelf |

## Signature moves

1. **The catalogue is a 3D stack of book spines** you scroll through; each spine shows author, title and the press mark in the cover's own materials.
2. **A tick-mark index on the left edge** that tracks your position in the stack.
3. **Tiny, confident type** — no big headlines anywhere; the objects provide the hierarchy.

## Why it works

The product is a physical book, so the interface *is* the books. Scale and colour come from the objects, which lets the typography stay quiet and literary. Nothing on the page is a generic web pattern.

## How to adapt

- When the product has a physical or visual form, render the catalogue as that form.
- Hierarchy does not have to come from font size; position, material and object scale can carry it.
- Let content own colour; keep the brand neutral.

## Watch-outs

- Only works with strong, consistent product imagery.
- Tiny headings need generous spacing and excellent type to not feel unfinished.
