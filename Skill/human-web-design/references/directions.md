# Directions

Pick **one** direction from the brief's physical object (SKILL.md pass 1, question 3). Mixing two directions is how pages end up generic. Each direction lists its decisions, a starting token set, what to avoid, and case files to study.

---

## 1. Warm Paper (crafted, friendly, studio)
**Object:** a well-made printed portfolio, a stationery set.
**Fits:** small studios, freelancers, agencies, consumer brands that want warmth.

- Type: humanist or friendly geometric sans, one family; headings 600 weight, slight negative tracking.
- Colour: warm off-white bg, lighter surface, warm near-black text, muted from text; single dark "ink" for primary buttons.
- Shape: pill controls + ~16px cards; tinted soft shadows.
- Signature options: work shown as physical objects (cards, frames, stacks) you can flip or fan; giant faded monogram watermark.
- Avoid: pure white, blue links, gradient anything.
- Study: `case-files/c-level-hideout.md`

## 2. Loud Product (energetic, creator tools, youth)
**Object:** a sticker sheet, a music festival poster, a toy box.
**Fits:** creative/AI tools, consumer apps, games, events.

- Type: very heavy (800–900) display, uppercase, tight leading ~1.0; same family for UI at regular weights.
- Colour: deep tinted dark base + 4–5 saturated colours, each mapped to something (mode, category, product).
- Shape: pills and 18px tiles; hairline borders on dark.
- Signature options: real outputs as the hero; a working input in the hero; per-word colour in headlines tied to the palette mapping.
- Avoid: purple-blue glow; colour used randomly; gradient text without a mapping.
- Study: `case-files/stockgen-landing.md`, `case-files/panic.md`

## 3. Editorial / Publisher (considered, literary, long-form)
**Object:** a book, a magazine, a printed report.
**Fits:** publications, research, essays, premium brands, foundations.

- Type: a text serif with real character; hierarchy may come from layout, not size (small confident headings).
- Colour: comes from the content (covers, photography); otherwise ink on paper.
- Shape: almost square (0–3px radius); rules and columns instead of cards.
- Signature options: the product rendered as the object (book spines, issues); reading-first layouts with marginalia.
- Avoid: rounded cards, icons, SaaS sections.
- Study: `case-files/stripe-press.md`

## 4. Swiss / Gallery (precise, confident, work-led)
**Object:** a museum wall label, a design annual.
**Fits:** design and architecture firms, portfolios with strong imagery, cultural institutions.

- Type: one neo-grotesk at mostly 400 weight; hierarchy from size steps and grey/alpha levels.
- Colour: white or near-white, black text, greys at fixed alphas; colour comes from the work.
- Shape: small 4px radius or none; grid is visible through alignment.
- Signature options: caption + body asymmetric grid; interactive sentence filters; huge project imagery.
- Avoid: decoration of any kind; more than one font.
- Study: `case-files/pentagram.md`

## 5. Industrial / Manual (technical, minimal, product-obsessed)
**Object:** a hardware manual, a spec sheet, a control panel.
**Fits:** hardware, dev tools, audio, engineering products, technical docs.

- Type: thin or regular grotesk/mono, many small sizes (9–12px) for labels, few large ones.
- Colour: monochrome (black/white/greys) with one signal colour (orange, red, lime) used like an indicator LED.
- Shape: square or tiny radius; hairlines; icons drawn like technical pictograms.
- Signature options: dramatic product photography as the hero; nav as a labelled control panel; numbered specs.
- Avoid: soft shadows, friendly illustration, marketing adjectives.
- Study: `case-files/teenage-engineering.md`

## 6. Quiet Software (calm, useful, precise)
**Object:** a well-organised notebook, a Muji product.
**Fits:** productivity tools, B2B apps, documentation, personal sites of engineers/designers.

- Type: one tuned sans (or sans + mono), modest scale, careful line-height.
- Colour: tinted neutral system with one restrained accent; light and dark designed separately.
- Shape: small radius (6–10px), hairline borders instead of shadows.
- Signature options: real UI fragments built in HTML as the hero; keyboard-shortcut hints; one beautifully crafted interaction.
- Avoid: dark-mode-with-glow SaaS template; bento grids of icons.
- Study: further-reading.md (personal sites of Rauno Freiberg, Emil Kowalski, Paco Coursey).

---

### If none fits

Combine the *object* idea with the closest direction's discipline (one type system, one palette logic, one radius system), and write a new direction entry in the brief using the same headings.
